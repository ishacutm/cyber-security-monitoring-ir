# Example response timeline

```mermaid
timeline
    title Synthetic exercise in UTC
    09:00 : Triggering event
    09:00:02 : Alert detected
    09:01:02 : Analyst acknowledgement
    09:02:02 : Incident opened
    09:05:02 : Investigation
    09:10:02 : Containment
    09:15:02 : Eradication
    09:20:02 : Recovery begins
    09:25:02 : Recovery validated and incident closed
```

Illustrative durations: MTTD = 2 seconds; MTTA = 60 seconds; MTTC = 600 seconds; MTTR = 1500 seconds. These are invented timings for teaching, not performance targets. Starting recovery is not recovery completion.
